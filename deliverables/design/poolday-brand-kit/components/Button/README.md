# Button

The off-white pill that carries the site's only call to action. Use `size="md"` (40px) in the nav and `size="lg"` (50px) in the hero and closing section.

- Provide: the label as children; `href` renders a link, otherwise a `<button>`; optional `icon` (a Lucide name).
- One button style exists. There is no secondary, outline or ghost variant on the site; do not invent one. For a secondary action use a text link in `ink-nav`.
- Label: say what happens, sentence case, no punctuation: "Book a 15 min demo".
- Colours: `cta` fill, `on-cta` label, `cta-hover` on hover, `focus` ring.
