# NavBar

The 88px top bar: wordmark left, centred links, one `md` Button right.

- Provide: optional `links` (`{label, href}` or `{label, menu: true}` for a dropdown trigger with a chevron), `cta` label and `ctaHref`, `homeHref`.
- Keep five links or fewer; the site uses Home, Solutions, Integrations, Pricing, Resources.
- Links are `nav` style in `ink-nav`, turning `ink` on hover; 32px apart.
- Sits directly on `bg`: no bar background, border or blur.
