# FilterTabs

Pill tabs that filter the video grid by audience, each with a 16px Lucide icon.

- Provide: `items` (`{id, label, icon}`), and either `value` + `onChange` or `defaultValue`.
- The selected tab gets the translucent `surface-glass` fill and `ink` text; the rest are `ink-muted` with no fill.
- Title Case labels, one or three words: All, Tech Industry, Apps & Games, Podcasts.
- Centre the row under a SectionTitle.
