# Hero

The homepage hero composition: Halftone behind a two-line headline, the definition lede and a large Button.

- Provide: optional `title`, `lede`, `cta`, `ctaHref`, `animate`.
- Spacing is fixed by tokens: `space-18` above, `space-8` to the lede, `space-10` to the CTA, `space-14` below.
- One per page. The headline is a statement with a period, at most two lines.
