# Icons

Lucide 1.48 (ISC licence), 24px grid, 2px stroke, round caps and joins, drawn with `currentColor`. As `<img>` they render in black: when used as files, recolour to `ink` or `ink-muted` via CSS mask or inline the SVG. The `Icon` component inlines them.

- `layout-grid.svg` — "All" filter tab.
- `briefcase.svg` — "Tech Industry" filter tab.
- `gamepad-2.svg` — "Apps & Games" filter tab.
- `mic.svg` — "Podcasts" filter tab.
- `chevron-down.svg` — nav dropdown triggers (Solutions, Resources).
- `volume-2.svg` — "Watch with sound" chip on video tiles (inferred placement).
