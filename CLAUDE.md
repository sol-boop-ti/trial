# Project: Poolday growth assignment

- `PLAN.md`: overall plan. `RUNBOOK.md`: the explicit step-by-step actions for the user. `METHODS.md`: how every step was made.
- **Always keep `METHODS.md` up to date.** Whenever a process is completed (a decision, an analysis, a Poolday run the user reports, a build), append an entry using its format: What · Tools · Inputs · Process · Decision & why · Output · Time/credits · Lessons. Include reproducible commands where relevant.
- When the user reports progress ("done B1, took 70 min, $40"), log it in METHODS.md and tick it in RUNBOOK.md.
- Never put model identifiers in files or commits.
